# Alpha Kids Practical Test Wiki

This wiki records the **whole process** of building a small bilingual (English/Roman Urdu) LLM parenting coach for the [Alpha Kids practical test](source-practical-test-brief.md): research, decisions, plans, the work board, and a record of every working session. It is written for both AI agents and human reviewers. Every link opens another page, as on Wikipedia.

## Current state (2026-11-18)

- **Phase:** research and planning. No app code yet.
- **Decided:** [flat LLM wiki](adr-0001-flat-llm-wiki.md); [minimal scope, built with TDD](adr-0002-minimal-scope-tdd.md); [Gemini free tier](adr-0003-llm-provider.md); [Roman Urdu only](adr-0004-roman-urdu-only.md); [local only, no deployment](adr-0005-local-only.md).
- **Next:** [safety and escalation research](ticket-0004-research-safety-escalation.md), [Roman Urdu research](ticket-0005-research-roman-urdu.md), then [stack](ticket-0007-choose-stack.md) and the [plan](plan.md).
